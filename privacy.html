3. 보관 및 외부 서비스

기기 저장 정보는 Android WebView(IndexedDB) 저장소에 보관됩니다. 앱 삭제, 브라우저 데이터 삭제, 또는 설정의 "전체 초기화" 기능으로 기기 저장값을 지울 수 있습니다.

  • 쿠팡 파트너스 링크: "쿠팡에서 찾기" 버튼을 누르면 쿠팡 파트너스 링크가 열립니다. 사용자가 버튼을 누를 때만 외부 앱 또는 웹사이트로 이동하며, 쿠팡의 개인정보 처리는 쿠팡의 개인정보처리방침을 따릅니다.
  • 마켓컬리 검색: "마켓컬리에서 찾기" 버튼을 누르면 마켓컬리 검색 페이지가 열립니다. 외부 서비스의 처리는 각 서비스의 정책을 따릅니다.
  • YouTube 레시피 검색: 사용자가 버튼을 누르면 레시피명으로 YouTube 검색 페이지가 열립니다. 검색어만 전달되며, YouTube의 처리는 YouTube의 정책을 따릅니다.
  • 관리자 링크 설정 조회: 장보기 화면에서 앱이 관리자 웹(Cloudflare Worker)의 공개 API를 호출해 재료별 파트너스 링크 설정을 받아옵니다. 이때 전달되는 정보는 요청 자체에 포함된 기본 네트워크 정보(IP 등)뿐이며, 사용자의 개인정보는 전송되지 않습니다.
